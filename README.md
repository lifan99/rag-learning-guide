# RAG 与 Agent 学习指南（公开版）

打开 index.html：先从“首次运行”观察示范；准备亲手写代码时，进入“PDF 动手起步”（index.html#guided-pdf）。它从终端、目录与环境开始，带你写一个 PDF 读取脚本，再独立改一处输出。也可下载 rag-learning-guide.zip，解压后阅读同版页面并运行实验。示范在包含 index.html 和 labs/ 的课程根目录运行；自己的脚本放在另一个自选项目目录，按页面标明的位置执行。

本仓库保存经筛选的公开静态页面、通用实验代码及虚构教学数据。正文由维护中的完整教材生成；私人题库、个人记录、第三方来源原文、完整教材 PDF/ZIP 和内部审查文件不在此仓库。合成测试验证工程行为，不代表真实模型质量或生产服务认证。

页面使用相对资源，可部署在 GitHub Pages 仓库子路径；站点入口是 index.html。公开下载包与本仓库页面使用同一份内容。外部参考资料仅保留链接，其权利与使用条件由各自来源说明；本仓库未擅自为第三方材料授予许可证。

实验使用方式与各阶段未验证限制见 labs/README.txt 及各实验子目录 README.txt。不要在仓库内保存个人资料、凭据、数据库状态或运行日志。
